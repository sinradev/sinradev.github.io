Features

Detailed documentation for every Sinra feature: filtering, drag-and-drop, global search, issue imports, and more.

Projects
Projects group capabilities that share a strategic purpose. They are the highest planning level in Sinra, above releases and cycles.
Advanced Filters
Sinra's filter system supports 40+ filterable fields with AND/OR rule groups. Filters persist in your session so you never lose your view. Learn how to build precise queries across your issue backlog.
Global Search
Sinra's global search finds issues, capabilities, projects, and releases simultaneously. Trigger it with Shift+F from anywhere in the app. Results are grouped by type with recently-viewed items as fallback.
Spec Pipeline
The Spec Pipeline is a Kanban board dedicated to PO/PM workflows. It visualizes all spec-writing issues grouped by capability and organized into columns based on their writing status. Drag cards between columns to update status instantly.
Issue Views
Sinra offers two ways to view your issues: a table list for detailed scanning and a kanban board for status-based workflow. Switch between them instantly without losing filters.
Bulk Operations
Select multiple issues at once and apply batch updates: status, assignee, release, cycle, labels, and platform in a single action.
Import Issues
Import issues into Sinra from a CSV file exported from any tool, with auto-mapping presets for Jira, Asana, Azure DevOps, and Linear, or directly from GitHub via OAuth.
Testings (QA)
Sinra integrates QA test cases directly into the development cycle. Create test cases on capabilities, run them during the cycle, and track acceptance without leaving the platform.
Retrospectives
Sinra automatically creates a retrospective for each release when it closes. The team adds structured feedback in four categories: Good, Bad, Improvements, and General.
Planning Meetings
Sinra centralizes planning meetings alongside the issues and releases they plan. Create structured meetings with agenda, participants, and outcomes — all linked to the cycle or release they govern.
Backlog
The Backlog view is where you assign capabilities to releases. Drag and drop capabilities into a release scope, and Sinra warns you when a release exceeds its capacity.
Phase Gate Reviews
Sinra implements V-model phase gates as structured reviews with explicit evaluation criteria and formal verdicts. Control quality at every stage of your development process.
Postmortems
Sinra provides a structured blameless postmortem workflow. Analyze incidents systematically, identify systemic causes, assign remediation actions, and build an institutional memory of what went wrong and how you fixed it.
Pages (Knowledge Base)
Sinra Pages is your team's internal knowledge base. Write rich-text documentation, reference pages from issues and capabilities, and keep your product vocabulary in one place.
Team Management
Configure teams, roles, and availability rates in Sinra. The accuracy of this data drives the reliability of all capacity calculations.
Configuration
Customize Sinra for your organization: workflow statuses, labels, categories, and platforms. Everything configures without code from the settings panel.
CIR/CII and Timesheet Export
Build a supporting extract for the French R&D Tax Credit (CIR) or Innovation Tax Credit (CII), or a simple worked-hours report, directly from the issues you already track day to day, with no manual re-entry.
VCS Integration
Link your GitHub, GitLab or Bitbucket repositories to SINRA to automatically advance the development status of issues and capabilities from git events: PR opened, review approved, merged, pushed.
