Navigation

The sidebar is organized by project phase: a Workflow section with six steps (Specify, Refine, Plan, Build, Verify, Learn) for the work in progress, and a Data section with the complete lists.

Overview

The sidebar follows the order in which a project moves forward. Read it from top to bottom.

AreaContent
DashboardYour home view, tailored to your role
Current cycleDirect access to the running cycle. For a developer, it is their own cycle (their issues, their workload). For other roles, it is the organization’s cycle
WorkflowSix collapsible steps, from specification to lessons learned
DataThe six complete lists: Projects, Capabilities, Issues, Releases, Cycles, Testings
Pages, TemplatesKnowledge base and reusable models
AdministrationTeams, roles, users, configuration, organization

The six Workflow steps

StepWhat you find thereWhat it is for
SpecifySpec PipelineTrack spec writing per capability
RefineRefinement queue, Refinement sessionsRefine and estimate capabilities that are ready
PlanPlanning meetings, BacklogDecide the scope of a release or a cycle
BuildMy issues, Current release, Current capabilities, Current projectsDeliver the committed work
VerifyCurrent testings, Phase Gate ReviewsValidate before shipping
LearnRetro, PostmortemsLearn from a release or an incident

Key point: Workflow answers “what should I do now?”, Data answers “where is this item?”. Workflow entries point to work in progress, Data entries point to the complete lists, history included.

A few useful landmarks:

  • Only one entry is highlighted at a time, and the matching step expands by itself.
  • The Workflow and Data labels and the step names are shown in English whatever your language.
  • In collapsed mode (button at the top left), section titles become thin separators and each step opens a floating menu.
  • The menu at the bottom of the sidebar (your avatar) gives access to your profile, security, the getting started guide, API tokens and the documentation.
