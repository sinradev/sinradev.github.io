1. Le Service

Sinra est un outil de gestion de projet pour les équipes logicielles : capabilities, issues, cycles, releases, tests et fonctionnalités associées, tel que décrit sur sinra.dev et dans la documentation intégrée. THEL peut ajouter, modifier ou retirer des fonctionnalités dans le temps ; toute réduction substantielle des fonctionnalités pour les offres payantes sera communiquée à l’avance dans la mesure du raisonnablement possible.

2. Comptes et offres

  • Vous devez fournir des informations exactes lors de la création d’un compte et garder vos identifiants de connexion confidentiels. Vous êtes responsable de l’activité effectuée sous votre compte.
  • Le Service est proposé avec un essai gratuit (14 jours, toutes les fonctionnalités, sans carte bancaire), suivi d’offres payantes facturées par siège, tel que décrit sur la page tarifs. Les prix sont affichés hors taxes applicables sauf mention contraire.
  • Les abonnements se renouvellent automatiquement pour la même période (mensuelle ou annuelle) sauf annulation avant la date de renouvellement. Vous pouvez annuler à tout moment depuis les paramètres de votre compte ; l’annulation prend effet à la fin de la période de facturation en cours.
  • THEL peut suspendre ou résilier un compte en cas de non-paiement, de manquement aux présentes CGU, ou d’usage illicite, avec préavis dans la mesure du raisonnablement possible.

3. Vos données

  • Sinra est conçu pour des données de développement logiciel et de gestion de projet. Il n’est ni conçu ni certifié pour traiter des données de santé, des données de comptes financiers, ou d’autres données personnelles sensibles. Ne soumettez pas de telles données dans le Service ; utilisez des données fictives ou anonymisées dans vos contextes de test ou de démonstration. Cette restriction est détaillée dans le DPA.
