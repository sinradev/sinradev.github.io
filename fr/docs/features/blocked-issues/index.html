Issues bloquées

Déclarez que vous êtes bloqué, indiquez qui peut vous débloquer, voyez depuis combien de temps une issue est coincée et listez toutes les issues bloquées.

Vue d’ensemble

Quand vous ne pouvez plus avancer sur une issue, dites-le depuis l’issue elle-même. Sinra la passe au statut bloqué, interpelle la bonne personne et affiche depuis combien de temps elle est coincée.

Déclarer que vous êtes bloqué

  1. Ouvrez l’issue et choisissez Je suis bloqué dans les actions à droite.
  2. Écrivez pourquoi vous êtes bloqué et choisissez qui peut vous débloquer. Les deux sont obligatoires.
  3. Validez. L’issue passe au statut bloqué de son type et un commentaire avec votre motif est publié. La personne choisie y est mentionnée et la mention est marquée En attente de réponse : elle apparaît dans ses questions à traiter.

L’action n’est pas proposée si l’issue est déjà bloquée, terminée, ou si son type n’a pas de statut bloqué.

Le badge

Un badge Bloqué depuis X j (ou Bloqué aujourd’hui) apparaît sur les cartes du kanban, dans les listes d’issues et dans la vue du cycle. Survolez-le pour lire le motif.

Débloquer

Choisissez Débloquer sur l’issue. Elle retrouve le statut qu’elle avait avant le blocage, le badge disparaît et une ligne dans les commentaires indique qui l’a débloquée. Changer son statut à la main vers un autre statut la débloque aussi.

Toutes les issues bloquées

Issues bloquées, dans le menu Construire, liste toutes les issues bloquées de l’organisation, les plus anciennes d’abord, avec leur motif, la personne qui peut les débloquer et leur cycle.

Seul le blocage en cours est conservé : les blocages passés ne sont pas enregistrés.

Passer une issue à un statut bloqué depuis la liste de statut ou par glisser-déposer est refusé avec un message : utilisez Je suis bloqué, pour que le motif et la personne qui peut débloquer soient toujours enregistrés.
